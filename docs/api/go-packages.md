# Go Packages

For developers building custom agents or extending the registry, the following Go packages are available.

## Core Packages

### `internal/orchestrator`

The heart of the logic.

*   `Orchestrator`: Main service provided for execution.
*   `Agent`: Interface that all agents must implement.
*   `Task`: Struct definition for units of work.
*   `Result`: Struct definition for outputs.

### `internal/mcp`

MCP Server implementation.

*   `MCPServer`: The server struct.
*   `Tool`: Definition of an MCP tool.
*   `Resource`: Definition of an MCP resource.

### `api/v1alpha1`

Kubernetes API definitions (generated by Kubebuilder).

*   `AgentCatalog`
*   `MCPServerCatalog`
*   `DiscoveryConfig`

## Usage Example

Importing the orchestrator to build a custom CLI tool:

```go
package main

import (
    "context"
    "github.com/agentregistry-dev/agentregistry/internal/orchestrator"
)

func main() {
    // Initialize
    orch := orchestrator.NewOrchestrator(...)
    
    // Create task
    task := &orchestrator.Task{
        Type: orchestrator.TaskTypeCode,
        Description: "Hello World",
    }
    
    // Execute
    result, err := orch.ExecuteTask(context.Background(), task)
    // ...
}
```
